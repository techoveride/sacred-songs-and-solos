How to Publish Hymn Updates Live

Follow these 3 easy steps to deploy updates to all mobile app users

1

Upload hymn_updates.json to your Web Hosting

Download the updated JSON from this dashboard and upload it to your website or hosting:

  • Your Own Web Hosting (Recommended): Upload hymn_updates.json via cPanel File Manager or FTP to public_html/hymn_updates.json. Your URL will be: https://yourdomain.com/hymn_updates.json.
  • GitHub Gist: Create a public gist named hymn_updates.json and copy the Raw URL.
  • Firebase Hosting: Run firebase deploy --only hosting.
2

Update Firebase Remote Config

Go to your Firebase Remote Config Console and set:

Parameter Key Value to Set Purpose
hymn_catalog_version 2 (Increment by 1) Notifies app that a new catalog version is available
hymn_updates_url https://yourdomain.com/hymn_updates.json The direct URL where app downloads the JSON
Important: Click Publish changes at the top right of the Firebase Remote Config screen!
3

App Users Receive Updates Automatically!

When users launch the app or tap "Check for Hymn Updates" in the drawer menu, the new hymns are fetched and stored in SQLite. All user favorites and custom songs remain safe!
